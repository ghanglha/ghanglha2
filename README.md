# ganglha.net

Jekyll with Tina headless CMS integration.

## Prerequisition
- Ruby Gems
- Knowledge of Jekyll Static Site generator
- Tina headless CMS for Content management
- Node.js
- Basic knowledge of Node Package Manager (NPM)

## Process:
- git clone git@github.com:ghanglha/ghanglha2.git
- Move directory to /ghanglha
- install node packages by running ``npm install``
- after that you can run the jekyll/Tina CMS instance with `` npm run dev ``
